# Board Of Science ![Construct 3](https://img.shields.io/badge/Made%20With-Construct%203-blue)
A board game with a science twist. Click the dice to start! Answer quiz questions and gain the most score. Correct quiz answers grant +2 and incorrect answers grant -2.
Built in Construct 3, with JS.
